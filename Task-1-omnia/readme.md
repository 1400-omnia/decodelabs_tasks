# 🤖 DecodeBot - Rule-Based AI Chatbot

## 📌 Project Overview

DecodeBot is a simple rule-based AI chatbot built with Python.

It uses predefined rules and responses to simulate basic human-like conversation, including greetings, simple questions, help commands, and exit commands.

The project also includes a graphical user interface (GUI) built with Tkinter.

## ✨ Features

- 👋 Greeting detection
- 💬 Predefined responses
- 🎲 Multiple responses for selected inputs
- ❓ Help command
- 🤔 Unknown-input handling
- 🔄 Continuous conversation
- 🖥️ Graphical User Interface (GUI)
- 🚪 Exit and quit commands
- 📄 JSON-based response storage

## 🛠️ Technologies

- Python
- JSON
- Tkinter
